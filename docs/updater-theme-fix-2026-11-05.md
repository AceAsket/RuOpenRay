# Окно обновления: исправление к 0.5.5

В окне обновления Xray и разделе обновления панели завершено применение
текущей светлой и тёмной темы: карточки, архитектура, кнопка закрытия,
параметры резервной копии, выделение релизов и вывод результата используют
общую палитру. Подпись архитектуры больше не выделяется ярким цветом
и верхним регистром. На узких экранах кнопка закрытия остаётся справа
от заголовка, длинные строки переносятся внутри окна.

Исправлены связанные состояния интерфейса:

- Пока список загружается или недоступен, окно не утверждает, что
  установлена актуальная версия.
- Релиз без сборки для архитектуры роутера нельзя установить кнопкой формы.
- Во время установки выбор релиза, фильтр и флажок резервной копии
  недоступны для изменения.
- Сообщение об актуальности указывает на проверяемый канал.

Обработчики установки, API и сетевые настройки не изменены. Выпущенный тег
`v0.5.5` сохраняется; дополнительное исправление фиксируется отдельным
коммитом ветки `dev`, пакет OpenWrt получает выпуск `0.5.5-r2`.

## Проверки

- 368 frontend тестов, smoke (87 проверок, 67 рендеров), загрузка приложения.
- Настоящий `app.js` с синтетическим API в браузере: оба раздела обновления
  в двух темах на ширинах 320, 390 и 1265 px — 12 состояний без
  горизонтального переполнения. Положение кнопки закрытия проверено
  относительно заголовка на всех шести состояниях окна Xray.
- Переключение фильтра, флажка и темы сохраняет выбранные параметры.
  Отсутствующая сборка, ошибка загрузки и пустой список проверены отдельно.
- Регрессии для загрузки, ошибок, неизвестной версии, недоступных сборок
  и блокировки полей во время установки.

Обновление стенда заменяет только панель с резервной копией и проверкой
контрольных сумм. Активная конфигурация, черновик и процессы Xray/AdGuard
сохраняются.
