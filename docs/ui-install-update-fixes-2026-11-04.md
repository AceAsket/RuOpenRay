# Исправления интерфейса установки и обновления RuOpenRay

Исправления по [аудиту](ui-install-update-audit-2026-11-04.md) отправлены в
`origin/dev` коммитом `83d5865`; OpenWrt пакет `0.5.2-r5` закреплён коммитом
`b4824bd`. На тестовом `192.168.50.117:9090` установлена
сборка `0.5.2+audit.20261104.2`. Ниже приведены результаты этой приёмки;
дальнейшие сборки сохраняют ту же логику исправлений.

| I01 | Повторная установка сохраняет действующие UCI параметры, дополнительные секции и схему Xray. После скачивания настройки перечитываются под общей блокировкой; явные переменные окружения остаются overrides. |
| I02 | Кандидат проходит SHA и self-check до остановки панели. Ошибка записи или готовности запускает возврат бинарника и служебных файлов. Если блокировка не позволяет безопасный возврат, копии сохраняются с явной ошибкой. |

| U04 | Действие «Применить профиль» перезапускает Xray через механизм отката; сохранённый и локальный черновик остаются доступными. |

Дополнительно исправлены стрелки порядка DNS: одинаковые SVG значки на
прозрачном фоне, цвета текущей темы, состояния hover/focus/disabled. Размер
кнопок — 30 px на компьютере и 40 px на мобильном устройстве.

В `0.5.3` также приведены к текущей теме карточки Geo Doctor, метки типов и
статусов, подписи DAT файлов и кнопка выбора файла. Удалены прежние чёрные

компьютере и при ширине 390 px; функциональная логика Geo не менялась.

После выпуска `0.5.3` исправлен отступ SNI: между формой поиска и статистикой
добавлено 16 px. Колонки формы стали гибкими, чтобы поля не выходили за
пределы панели на небольших экранах компьютера. Пустое состояние, поиск и
готовые результаты проверены на синтетических данных в обеих темах при
ширине 1440, 1100 и 390 px.

## Границы поведения

Shell installer выполняет откат при обнаруженных ошибках и обработанных
сигналах. Аварийное отключение питания или SIGKILL посреди shell установки
не покрывается этим trap; для такого восстановления сохранены копии.
Самообновление через API использует собственный durable журнал и boot-helper.

Исторические каталоги geo без нового манифеста автоматически не удаляются:
очистка выводит их имена и причины пропуска для ручной проверки. Legacy API
upsert профилей сохранён для существующих клиентов импорта; новые UI действия
явно используют защиту создания и ревизии редактирования.

Если старый recovery-helper не передал ID попытки либо за три минуты результат
обновления нельзя подтвердить, интерфейс показывает «Требуется проверка».
Автоматическая перезагрузка запрещена при редактировании форм и неприменённых
настройках; ручная перезагрузка предупреждает о потере несохранённого ввода.

Локальные результаты и снимки экрана находятся в игнорируемом каталоге
`.private/audit-ui-install-update-20261104/`.
