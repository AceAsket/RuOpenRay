# Пагинация подключений на Панели

Блок «Серверы» показывал только первые пять подключений, хотя заголовок
считал весь список. Теперь подключения доступны страницами по пять карточек.
При восьми серверах первая страница показывает 1–5, вторая — 6–8.

Под списком отображаются диапазон, номер страницы и кнопки «Назад» и
«Вперёд». На границах списка соответствующая кнопка недоступна. При пяти
подключениях или меньше навигация скрывается.

Обновление статистики и переключение темы сохраняют страницу. После удаления
подключений номер ограничивается оставшимися страницами. Проверка и выбор
сервера используют исходный tag независимо от страницы. Перелистывание
не меняет конфигурацию, подписки или маршруты.

Проверки: 434 frontend-теста, smoke (87 проверок, 67 рендеров), загрузка
приложения; браузерная проверка восьми подключений, обеих тем, клавиатуры
и экрана 320 px без горизонтального переполнения.
