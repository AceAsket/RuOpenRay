# Причины отказа применения и проверка серверов

Исправление к 0.5.6 сохраняет полный ответ API при ошибке применения.
Раньше HTTP 422 терял вложенный вывод Xray, а старый результат проверки
мог показываться под новым сообщением о сохранении или удалении сервера.

## Поведение интерфейса

- Причина проверки, ошибка перезапуска и сведения об откате показываются
  в уведомлении и рядом с этапами применения. Черновик при отказе сохраняется.
- Конфликт действующей конфигурации включает кнопку загрузки актуального
  черновика. Автоматического повторного применения поверх изменений нет.
- Индикатор прежней неудачной попытки скрывается после изменения черновика.
- На «Панели» и в «Подключениях» серверы, которые отклонил Xray,
  выделяются красным с надписью «Xray не принимает» и причиной.
- Подтверждённый запрет публичного VLESS без TLS или другого шифрования
  объясняется по-русски; исходный вывод доступен в технических подробностях.
- Кнопка «Проверить конфигурацию серверов» выполняет проверку без применения.
  Доступность сервера в сети остаётся отдельным показателем.
- Изменение или удаление сервера и смена версии ядра сбрасывают старую отметку.
  Запоздалый ответ проверки прежнего ядра не помечает новый результат.
- Исправлены круговые стрелки кнопки обновления подписки и их выравнивание.

## Проверка ядром

API возвращает `outboundErrors` с тегом, причиной и `source: "xray"`,
а также `outboundErrorsComplete`. Ошибка назначается серверу только по
фактическому выводу установленного ядра с однозначным тегом.

Для поиска нескольких ошибок уже отклонённый выход заменяется нейтральным
только во временной копии, сохраняя тег и ссылки правил. Дополнительная
диагностика ограничена восемью ошибками и пятью секундами. Оригинальный
результат проверки, конфигурация, профиль и работающие сервисы не меняются.
Неполный результат не объявляет остальные серверы исправными.

## Проверки

- 399 frontend тестов, smoke (87 проверок, 67 рендеров), загрузка приложения.
- HTTP 422 и 200 с ошибкой, отказ перезапуска и откат, конфликт версий,
  транспортный сбой, повторное применение и сохранность черновика.
- Интерактивная проверка настоящего `app.js` с синтетическим API:
  красные карточки на двух страницах в двух темах на 320, 390 и 1265 px,
  подробности ошибки, сброс устаревшей отметки, конфликт и успешное применение.
- Значок подписки отцентрирован и сохраняет квадратные пропорции во всех
  шести сочетаниях темы и ширины.
- Полный Go suite и vet. Реальные Xray 26.3.27, 26.9.9, 26.10.21 и 26.10.31
  проверяют диагностику нескольких ошибочных outbound и сохранность данных.
  Проверка запрета VLESS без шифрования привязана к 26.10.31;
  на более старых закреплённых ядрах этот сценарий пропускается.

Выпущенный тег `v0.5.6` сохраняется. Исправление публикуется отдельным
коммитом `dev`, пакет OpenWrt получает выпуск `0.5.6-r2`.
