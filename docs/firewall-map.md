# Карта firewall

Пробный раздел доступен в **Сценарии и правила → Карта firewall**.
Он читает действующие правила nftables на роутере. Нажмите «Обновить карту»,
чтобы получить новый снимок; автоматического опроса нет.

Схема показывает пять основных этапов Netfilter для трёх сценариев:
LAN → Интернет, LAN → роутер и роутер → Интернет. Нажатие на этап открывает
его базовые цепочки, отсортированные по числовому приоритету. При равных
приоритетах фактический порядок между цепочками не гарантирован.
Таблица RuOpenRay отмечена отдельно.

В выбранной цепочке правила остаются в порядке ядра. Отображаются условия,
действия, handle, комментарии и счётчики. Переходы `jump` и `goto` открывают
дочернюю цепочку; кнопка возврата возвращает к предыдущей. Выражения nftables
можно раскрыть отдельно. Неизвестные выражения остаются видимыми.
Длинные цепочки показываются порциями по 200 правил с кнопкой продолжения.

Переключатели IPv4 и IPv6 выбирают соответствующее семейство вместе с `inet`.
В режиме «Все семейства» доступен список всех цепочек, включая ARP и bridge,
с поиском по имени, таблице и семейству. На узком экране схема прокручивается
внутри своей области, а этапы доступны также обычными кнопками.

## Что означает подсветка

Подсветка показывает общую схему выбранного сценария. Она **не является
трассировкой конкретного пакета** и не предсказывает итоговый verdict.
Условия правил, NAT, метки, TPROXY и policy routing могут изменить или
завершить фактический путь. Раздел не включает nftrace и не добавляет
диагностические правила.

Счётчики относятся к моменту снимка. В `inet` они общие для IPv4 и IPv6,
а ускоренные flowtable потоки могут обходить показанные счётчики.
«—» означает отсутствие счётчика, а не нулевой трафик. Содержимое именованных
наборов не читается. Для системы без nftables с JSON показывается ошибка;
отдельный сборщик iptables в эту пробную версию не входит.

## Происхождение

Идея раздела предложена по снимку Metro Map в ASUSWRT. На 7 ноября 2026
готовой реализации не найдено в проверенных публичных ветках
[asuswrt-merlin-xrayui](https://github.com/DanielLavrushin/asuswrt-merlin-xrayui/branches),
последних PR и нескольких свежих форках. На снимке карта находится в разделе
Firewall самой прошивки; это может быть отдельная доработка.
Реализация RuOpenRay написана самостоятельно, без копирования исходников ASUS
или XrayUI. API и его ограничения описаны в [api.md](api.md).
