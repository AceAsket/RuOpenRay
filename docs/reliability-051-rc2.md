## Проверки 22 октября 2026

Исходная панель RC1 и её данные сохранены на VM до первой установки. Обновления
панели сохраняли процесс Xray, конфигурацию, DNS, firewall, профили и черновик.
Первое скачивание нового ядра с GitHub завершилось сетевой ошибкой на подготовке,
без замены работающего ядра. Следующая попытка прошла штатную транзакцию
`/core/update`: проверка официального SHA-256, конфигурации, резервная копия и
контроль запуска. На VM установлен Xray 26.10.21; `.1` не администрировался.

Сравнение временного выхода с фрагментацией `120-220,0-8,tlshello` на новом ядре:

| Вариант | TLS 1.2 | TLS 1.3 |
| --- | --- | --- |
| Запрос с роутера | 5/5 | 3/5 |
| VPN с фрагментацией | 5/5 | 3/5 |
| Тот же VPN без фрагментации | 5/5 | 5/5 |

Активные маршруты при сравнении не применялись, основной процесс не
перезапускался, временный выход удалён. Отдельная серия через интерфейс дала
6/6 через другой выбранный VPN и 2/3 TLS 1.3 на прямом запросе. Наличие ошибок
на прямом пути VM не доказывает проблему провайдера: внешний шлюз может
перехватывать этот трафик. Результаты подтверждают полезность сравнения и
сохранение проблемы в определённой конфигурации; единственная причина всех
TLS-обрывов и универсальное исправление не установлены.

Проверено дополнительно:

- Go unit-тесты, `go vet`, 132 frontend-теста, smoke: 87 проверок / 66
  рендеров, запуск приложения. Отдельные тесты проверяют оборванный HTTP 200,
  сертификаты, сохранение ввода, целостность ZIP и откат после ошибки записи.
- Настоящие TLS-туннели на старом и новом ядре. CI также проверяет 26.9.9.
- Виртуальный LAN-клиент на 26.10.21: 24 DNS-запроса по UDP/TCP к локальному
  и перехватываемому внешнему DNS, A/AAAA/TXT/MX/HTTPS и рекламный домен;
  HTTPS direct/VPN, block и увеличение счётчиков IPv4 TPROXY. Временная сеть
  полностью удалена, исходные процессы и настройки сохранены.
- Native API и интерфейс AdGuard: добавление временного Popup-фильтра,
  переключение и удаление; исходные списки, пользовательские исключения,
  upstream и процессы сохранены. Временные списки не оставлены включёнными.
- Проверен архив из 20 файлов с native YAML, кэшем фильтров, UCI и
  init-скриптами. Изменены конфиг Xray, YAML и кэш AdGuard, добавлены лишние
  файлы; полное восстановление вернуло точные хеши и удалило эти файлы.
  Защита от восстановления при работающих службах сработала. Скачанный ZIP
  совпал по SHA-256, запрос без входа получил 401.
- При остановленном основном Xray случайные некэшированные DNS-имена
  разрешались по UDP/TCP, querylog подтверждал обращение к HTTPS upstream.
- После восстановления и перезагрузки VM службы запустились автоматически,
  конфиг, черновик, имена групп и подборки совпали со снимком. DNS и HTTPS
  через SOCKS вновь прошли проверку. Настройки и очередь B4 не менялись.

После перезагрузки выполнены ещё три серии через два VPN без фрагментации:
35/36 HTTPS-запросов прошли, один TLS 1.3 через первый сервер завершился
таймаутом 6 с; через Финляндию прошли 18/18. На прямом запросе VM — 30/36:
четыре TLS-ошибки и два таймаута. Основные службы, конфиг и черновик сохранены.
Таким образом, отсутствие фрагментации улучшает наблюдаемую картину, но
обещать полное устранение сетевых обрывов ещё нельзя.

## Опубликованный RC2

[Релиз v0.5.1-rc2](https://github.com/AceAsket/RuOpenRay/releases/tag/v0.5.1-rc2)
опубликован как prerelease. [Сборка тега](https://github.com/AceAsket/RuOpenRay/actions/runs/39789012221)
и [публикация пяти архитектур](https://github.com/AceAsket/RuOpenRay/actions/runs/39789012070)
завершились успешно.

На `.117` установлен именно скачанный Linux/amd64-артефакт, SHA-256 сверён
с отдельным файлом релиза и digest GitHub:
`000afd65cf657019bdd00f944873722c9eb37a52433995497f2fa668f0e676ef`.
Процессы Xray/AdGuard, конфиг, черновик, группы и LAN DNS при замене панели
не менялись. Создание, проверка и авторизованное скачивание архива из 20
файлов прошли; рекламный домен блокируется, свежий DNS UDP/TCP доходит до DoH,
HTTPS через рабочий SOCKS вернул 204 от Google и Cloudflare.

Дополнительная серия опубликованного бинарника через Финляндию дала 5/6:
один запрос TLS 1.2 превысил 6 с. Остальные ответы прошли проверку сертификата
и полностью прочитаны. Диагностика вернула ошибку и не объявила серию здоровой.
Таким образом, и этот выход пока нельзя считать полностью свободным от
таймаутов. RC2 готов для дальнейшего наблюдения, стабильный релиз отложен.
Повторная перезагрузка уже с опубликованным RC2 также прошла: службы
стартовали автоматически, сохранённые конфигурации и подборки совпали,
некэшированный DNS UDP/TCP и HTTPS через VPN работают.

### Исправление подписей после RC2

В тестовых подключениях префикс флага уже был сохранён как четыре буквальных
знака `?`. Диагностика TLS, DPI и доменов теперь показывает очищенное имя
и код страны; TLS также выводит отдельный SVG-флаг. Финляндия распознаётся
по отдельному токену `fin`. Значение option, передаваемый API тег, конфиг,
профили и маршруты сохраняются. На `.117` проверены отображение и смена
FI/RU; процессы Xray/AdGuard при установке панели не менялись. Пройдены
134 frontend-теста и smoke/boot. Это исправление ветки `5.0-test` после
опубликованного тега, установленное на `.117` отдельной тестовой сборкой.
