добавляются ниже; запись «готово» относится только к действительно выполненным
проверкам. Для SDK, native nft/TPROXY и длительного наблюдения unit-тестов недостаточно.

## Выполненные работы

- В `dev` реализован первый пакет конфигураций и обслуживания. API 0.2 требует
  ревизию при сохранении/удалении черновика. Снимок активного конфига и черновика
  защищён тем же Linux flock, что API/cron/CLI; scope блокировки — весь роутер,
  даже если у процессов разные каталоги данных.
- Ошибка restart не удаляет черновик и не отображается как успешное применение;
  следующий шаг комплексного apply прекращается. Фоновые refresh сохраняют
  локальные изменения, конфликт можно разрешить явной загрузкой актуального черновика.
- Смена кандидата подписки сохраняет dialerProxy и согласует saved profile;
  ошибка восстанавливает точный прежний профиль. Restore JSON также синхронизирует профиль.
- CLI читает UCI с приоритетом явных env, не создаёт default ActiveConfig
  и не запускает фоновые обработчики логов. Все cron generators передают пути
  DataDir/ActiveConfig/ProfilesDir/GeoDir/BackupDir/ServiceName и лимиты Go.
- Geo download ограничен 64 МиБ; multipart потоково пишется в файловую систему
  asset-каталога и ограничен до разбора. Полный набор готовится отдельно,
  проверяется protobuf framing и native Xray, затем заменяется с обязательной копией.
  Ошибки скачивания/проверки не изменяют рабочие базы; предусмотрен откат при отказе restart.
- Дополнительно найден и исправлен регистр кодов создаваемых категорий GeoIP/GeoSite:
  теперь на диске UPPERCASE. Проверка настоящим Xray выявила отказ старого lowercase
  кода; [загрузчик ядра 26.10.21](https://github.com/XTLS/Xray-core/blob/v26.10.21/common/geodata/geodat_loader.go)
  сопоставляет байты кода с учётом регистра. Читаемые UI-коды остаются прежними.
  Существующие базы на `.1` автоматически не переписывались.
- Remember-токены используют случайный постоянный ключ вместе с паролем;
  проверка expiry выполняется независимо от session map. Logout сохраняет отзыв
  на диске, обычные сессии ограничены 12 часами, попытки входа ограничены.
  Неавторизованная проверка токена не создаёт ключ на диске.
- SVG проверяется XML-парсером с разрешающим списком и показывается как image,
  добавлены CSP/nosniff/frame headers. Полная browser-приёмка импортов остаётся.
- Самообновление сверяет официальный digest/SHA независимо от зеркала и делает
  обязательную копию; shell installer сверяет SHA, готовит файл на целевой FS
  и сохраняет прежний binary. Watchdog после фактического перезапуска ещё нужен;
  обязательная rollback-копия пока сохраняется независимо от флага keepBackup.
- Диагностика HTTP больше не объявляет обрезанный HTTP 200 успешным; полное
  чтение ограничено 2 МиБ, превышение лимита явно считается неполной проверкой.
- На `.117` пройдены 15 первоначальных Linux regression-сценариев и native
  tunnel/sniffing/balancer suite с Xray 26.10.21. Дополнительный native geo-тест
  подтвердил отказ при исчезновении нужной категории, успешную установку валидной
  базы и native отказ невалидному профилю. Тесты выполнялись в отдельных каталогах.
- Изолированная временная Go-панель `.117` проверена по настоящему HTTP API:
  malformed JSON, stale revision, неудачный restart с сохранением черновика,
  нормализация старого профиля, native validation, logout/restart и действительная
  remember-сессия после restart. PID Xray/AdGuard и хеши действующих файлов `.117`
  до/после совпали. Установленная панель не заменялась. `.1` не изменялась.
- В CI добавлены race detector и native geo-тест для трёх закреплённых Xray.
  Результат CI будет зафиксирован после публикации коммита; он пока не объявляется успешным.

## Ближайшие незакрытые работы

1. A07: nft candidate check/атомарная замена и rollback файлов, policy routing, DNS.
2. A06/A14: независимый watchdog панели, проверка готовности процесса и DNS/VPN
   с baseline и несколькими целями без ложного отката по одному сайту.
3. A10: исправленный и проверенный SDK package, безопасный first-run вместо admin.
4. Приёмка cron/ENOSPC/reboot, browser E2E, длительное наблюдение `.117` и B01–B12.

Это статус реализации, а не заявление о готовности всех P1 или стабильной 0.5.1.
