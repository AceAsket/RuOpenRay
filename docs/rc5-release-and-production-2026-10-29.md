# RC5: выпуск и установка на основном роутере

По отдельному запросу опубликован предварительный релиз
[v0.5.1-rc5](https://github.com/AceAsket/RuOpenRay/releases/tag/v0.5.1-rc5)
и обновлена панель `192.168.50.1`. Тег указывает на
`a92c2e199d1488dcdd0cac1ff3e68e6c9b2d2055`; версия SDK — `0.5.1_rc5-r1`,
закреплённый источник SDK — `c41259426f1f92b319daa1a4cf0f8109dc70a02e`.
Go/frontend-код соответствует принятому RC4 r11; изменены версия, recipe и
описание релиза. Стабильный Latest этим prerelease не заменяется.

## Проверка выпуска

- Локальные Go-тесты, 164 frontend-теста, smoke 87 проверок/66 renders и app boot
  прошли. Проверки форматирования и отсутствия приватных данных пройдены.
- [Релизный CI](https://github.com/AceAsket/RuOpenRay/actions/runs/40782693861)
  успешно проверил три версии Xray, собрал пять архитектур и опубликовал релиз.
- [Общий CI](https://github.com/AceAsket/RuOpenRay/actions/runs/40782689410)
  прошёл, включая race/vet и матрицу Xray;
  [OpenWrt SDK CI](https://github.com/AceAsket/RuOpenRay/actions/runs/40782689333)
  также завершился успешно.
- Загруженные официальные ARM64/amd64 бинарники сверены с SHA-256 релиза.
  ARM64 Go build info подтверждает Go 1.27.3, нужную архитектуру, revision тега
  и `vcs.modified=false`.
- До переноса на `.1` официальный amd64-артефакт запущен на `.117` в отдельном
  DataDir с listener на loopback. Пройдены self-check, HTTP startup, native
  проверка конфига установленным Xray и сверка встроенных JS с исходниками.
  Основные config/draft, PID служб и сеть `.117` сохранились; fixture удалён.
- На `.117` установлен SDK RC5 r1 с сохранением настроек, профилей, черновика,
  процессов Xray/AdGuard. Хеш загруженной панели совпал с установленным файлом,
  JS и загрузочный helper — с исходниками. Пакет и SHA-256 добавлены в релиз
  с явной маркировкой `x86_64-openwrt25.12.4`; digest GitHub upload проверен.
  На ARM64/opkg `.1` этот APK не устанавливался.

## Что изменилось на `.1`

Версия панели: `0.5.1-test.447+1c0ef96` → **`v0.5.1-rc5`**.
Установлен официальный ARM64-файл релиза:

```text
f06f134f5dc369f879083de9c1b2e1ce4da4636ddbce9081cb127464de69575a
```

Существующий init сохранён с его UCI-путями и параметрами. Добавлен только
вызов `ruopenray-recover-app` до старта панели и установлен сам helper;
`jsonfilter` уже был доступен. Файлы продвигались с `sync` по шагам.
Перезапущена служба панели. Проверка readiness, загруженного executable,
helper/init, встроенных JS и состояния завершилась за **9,4 с**, включая
последующие контрольные запросы; это не измерение длительности недоступности UI.

Сохранены по API и контрольным хешам:

- активная конфигурация, отсутствие черновика, профили и сохранённые настройки;
- учётные данные, DNS upstream, фильтры и настройки AdGuard;
- Xray, его конфигурация, nftables и policy routing, UCI сети/firewall/DHCP;
- PID Xray **9387** и AdGuard **1491**: эти процессы не перезапускались.

Маршруты, fragmentation и DNS upstream в этом переносе не редактировались.
До старта и после установки pending-журналов не было; сетевое восстановление
не запускалось. Кандидат заранее прошёл self-check на ARM64-роутере.

## Контроль связи

До и после обновления отдельно успешны по 6 DNS-проверок (UDP/TCP для трёх
доменов) и по 6 HTTPS-проверок: direct, VPN, Discord и GitHub favicon.
Независимый монитор работал до, во время и после замены панели **181 с**:

| Проверка | Успех |
| --- | --- |
| DNS UDP/TCP | 178/178 |
| HTTPS через рабочий SOCKS к Cloudflare, gstatic и Discord | 29/29 |
| PID Xray/AdGuard и контроль сетевого состояния | 66/66 |

Монитор не зафиксировал сбоев в этом окне. Он не измеряет каждый пользовательский
поток и не заменяет длительную приёмку. Предыдущие GitHub/TLS-таймауты и первый
DNS timeout после тестового reboot не объявляются исправленными выпуском RC5.
Ограничения описаны в [отчёте приёмки](recovery-and-ui-acceptance-2026-10-29.md).

## Резервная копия и откат

На `.1` сохранён каталог `/root/ruopenray-backups/panel-rc5-20261029/`
с режимом 0700: старый бинарник, init, архив настроек (0600), SHA-256,
сведения о прежнем helper и rollback-скрипт. Архив также скачан в приватный
локальный каталог и проверен по SHA-256. Секреты и архив не включены в Git.

Независимый watchdog был запущен до замены файлов. Контроллер подтвердил обновление
после контрольных проверок. При ошибке watchdog возвращает файлы панели; сетевые
настройки при откате не восстанавливаются поверх пользовательских изменений.
Файл `committed` подтверждает успешную установку; резервная копия оставлена
для ручного возврата. Временный бинарник из `/tmp` удалён.

Для ручного возврата подготовлен `sh /root/ruopenray-backups/panel-rc5-20261029/restore-now.sh`.
Скрипт проверяет копии и отказывается работать, если панель после RC5 уже
заменена другим бинарником. Его синтаксис проверен; на работающем RC5 откат
не выполнялся.
