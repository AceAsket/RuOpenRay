# Пустые исключения сниффера при обновлении Xray

В Xray 26.3.27 `sniffing.domainsExcluded: [""]` не мешал разбору SNI. В 26.10.21 непомеченные доменные исключения разбираются как подстроки (`Domain_Substr`). Пустая строка совпадает с любым доменом: сниффер исключает всё, доменные правила не получают имя назначения, а прозрачный TCP-трафик может уйти в правило «Остальной трафик» вместо VPN.

Характерный симптом: сайт открывается через SOCKS с передачей имени домена, но не открывается с LAN-клиента через прозрачный перехват. Проверка `xray run -test` проходит: конфигурация синтаксически допустима.

RuOpenRay удаляет только пустые и состоящие из пробелов элементы `domainsExcluded` при чтении/сохранении черновика, проверке и записи активной конфигурации. Непустые исключения, их порядок и повторы, остальные настройки сниффера, правила маршрутизации и DNS сохраняются. Некорректные значения других типов оставляются для обычной валидации Xray. Чтение старого черновика само по себе файл не переписывает.

Перед заменой ядра панель отклоняет активный конфиг с такими пустыми исключениями. Сначала нужно проверить и применить конфигурацию через RuOpenRay; после очистки можно обновлять ядро. Проверка совместимости не меняет рабочий файл и не перезапускает сервис.

`TestXraySniffingExclusions` проверяет TLS с настоящим Xray и локальным HTTPS-сервером с доверенным тестовым сертификатом. Назначение соединения задаётся IP-адресом; только извлечённый SNI может направить его в разрешённый выход. Проверяются исходный пустой элемент, нормализованный список и сохранение осмысленного исключения. Внешний DNS, публичные сайты и действующая конфигурация роутера тесту не нужны. Тест включён в CI для трёх закреплённых версий Xray.

27 октября 2026 г. воспроизведение на `.117` подтвердило разницу 26.3.27/26.10.21. После удаления четырёх пустых исключений на `.1` сайт Discord и HTTPS endpoint обновления приложения вернули HTTP 200 с LAN-компьютера. Версия ядра 26.10.21 сохранена; маршруты, DNS, firewall и неприменённые изменения сохранены. Перезапуск Xray выполнен после разрешения пользователя.
