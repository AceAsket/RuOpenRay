# RuOpenRay v0.5.2

Обновление интерфейса и опроса состояния роутера. Контракт API остаётся 0.2;
существующие настройки, профили и идентификаторы направлений сохраняются.

## Что нового

- Интерфейс в стиле GL.iNet: светлая и тёмная темы с сохранением выбора,
  единая навигация, иконки, панели, списки и уведомления.
- Компактная мобильная компоновка: управление сервисом рядом с заголовком,
  карточки серверов, одинаковые блоки ресурсов и адаптивные формы.
- Применение настроек показывает этапы операции, текущий шаг и завершённые
  действия. Прямое применение без списка этапов использует компактный
  индикатор. Анимация учитывает `prefers-reduced-motion`.
- Результаты проверок и операций выводятся сразу под заголовком страницы.
- Статистика трафика и фильтры «Домены / IP / DNS» используют единое
  компактное оформление; длинные теги серверов заменены понятными подписями.

## Исправлено

- Повреждённые префиксы флагов больше не показываются в названиях серверов,
  сообщениях подключения, подписках и подсказках. Значения `tag`, запросы,
  маршруты и содержимое редакторов остаются исходными.
- Устранены старые градиенты, слабый контраст, наложения кнопок и обрезанные
  элементы в раскрытых блоках, диагностике, Geo и таблицах AdGuard.
- Кнопка «Что изменится» сохраняет положение при раскрытии подробностей.
- Быстрый запуск показывает успех после завершения, сохраняет выбранный
  сервер и использует тег существующего transparent-входа. Изменение черновика
  или откат сбрасывают прежний результат; недостающие условия видны до запуска.
- Переходы по этапам мастера и кнопка «Продолжить» используют одинаковые
  проверки. Существующая группа балансировки сохраняется при подготовке
  конфигурации. Повторная попытка после частичного сбоя сохраняет исходный
  снимок для отката; изменения выбора во время запуска останавливают следующие шаги.
- Редактор балансировки проверяет реальные совпадения префиксов Xray,
  сохраняет выбранную группу при изменении списка и учитывает отключённые
  правила при переименовании и удалении. Отмена редактирования сохраняет черновик.
- Ошибки сохранения DNS и перезапуска dnsmasq больше не превращаются в успех
  только из-за совпавших настроек. Мастер не меняет DNS, который нельзя полностью
  восстановить поддерживаемым способом; для него доступен выбор «Не трогать».
- Применение сохраняет более новый черновик другой вкладки. Запоздалые ответы
  журнала, статуса и предыдущей сессии не заменяют текущие данные и не сбрасывают
  новый вход. Отключение Live сохраняет позицию просмотра журнала.
- Измерение CPU использует общий интервал не короче секунды. Фоновый опрос
  не пересекается сам с собой и пропускается на скрытой странице; начальная
  загрузка ограничивает параллельные запросы. Статус интеграций кешируется,
  серверный режим загружается при первом открытии.

## Для кого важно

Для пользователей мобильной панели и роутеров с ограниченными ресурсами,
а также при работе с длинными именами серверов и подробной диагностикой.

## Обновление и откат

Для обновления панели перезапускается только её служба. Обновление само
по себе не требует перезапуска Xray, dnsmasq или AdGuard и не применяет
черновик сетевых настроек. Применение маршрутов и firewall остаётся отдельным
действием пользователя.

Перед ручной заменой сохраните прежний бинарник, init-скрипт и настройки
панели. Для отката панели достаточно вернуть её бинарник и перезапустить
службу; восстанавливать сетевую конфигурацию для этого не требуется.

## Проверки

- `go test ./...`.
- Frontend-тесты, smoke и загрузка приложения.
- Мобильные вкладки в обеих темах на 320 и 390 px, переходная компоновка
  на 900–1024 px и десктоп до 2560 px.
- Заполненные формы, результаты диагностики и состояния применения
  проверяются на синтетических данных без запуска сетевых изменений.
- Подготовленные быстрым запуском конфигурации обоих режимов прошли проверку
  реальным Xray на тестовом OpenWrt без применения и перезапуска сервисов.

Приёмка интерфейса не заменяет отдельную проверку реальных изменений
маршрутизации, firewall и DNS для конкретной сети.
