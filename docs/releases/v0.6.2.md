# RuOpenRay v0.6.2

## Что нового

- Проверка прокси и серверов подписки показывает доступность TCP-порта и результат
  HTTP-запроса через Xray. Автоподбор подписки переключает выход после успешной
  проверки туннеля.
- Панель показывает порог ротации и число архивных копий журналов Xray.
- Обновлены значок панели и иконки браузера.

## Исправлено

- При ошибке записи редакторы geo-источников, geo-списков и сценариев сохраняют
  введённые данные. Загрузка дополнительного DAT использует сохранённый URL.
- Панель сообщает об ошибках записи настроек сервиса, очистки журналов,
  перезапуска Xray и запуска расписания через cron. Фоновое обновление
  сохраняет введённые настройки логирования и сервиса.
- Проверки учитывают заданное число попыток и таймаут. TCP-подключение быстрее
  миллисекунды считается успешным. Фоновый опрос сохраняет свежие результаты проверок.

## Для кого важно

Выпуск полезен при выборе сервера из подписки и работе со своими geo-источниками.
Обновление панели перезапускает сервис RuOpenRay. Конфигурация Xray, правила
перехвата и LAN DNS сохраняются, перезапуск Xray и AdGuard Home не требуется.

```sh
ruopenray-ui update --backup
```

## Проверки

- `go test ./...` и интеграционные тесты с Xray 26.10.31.
- `npm run test:frontend`, включая отказ записи, повторное сохранение и
  сохранение правок при фоновом обновлении.
